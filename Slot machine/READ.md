## ▶️ How to Run

1. Download or clone the project.
2. Open the project folder.
3. Double-click **`index.html`**.
4. Play the slot machine in your web browser.

## ✨ Features Implemented

* Three-reel slot machine
* Random symbol generation
* Starting balance of 1,000 credits
* Adjustable betting system
* Win and loss payout system
* Paytable for matching symbols
* Staggered reel spin animation
* Sound effects using Web Audio API
* Sound on/off toggle
* Spin counter
* Reset button
* Game-over detection
* Space and Enter keyboard controls
* Responsive design for desktop and mobile
* Accessibility features using `aria-live`
* Reduced-motion support
* Retro synthwave space-themed design
